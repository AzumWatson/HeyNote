# 2026-07-19 工作汇总

## 今日目标

在 AzumWatson/HeyNote 的基础上，将扩展从原先偏图片流的浏览体验，逐步调整为更接近小黑盒原版论坛的文字优先浏览体验，并补齐搜索、分区、详情和可维护性相关能力。

## 已完成

- 梳理项目结构：确认项目是 Manifest V3 浏览器扩展，使用 Vite、React、TypeScript 构建，核心入口包括 `domain-claim`、`domain-entry`、`background` 和 `search-bridge`。
- 调整信息流展示：弱化图片主导的卡片展示，让标题、摘要、作者、时间、互动数据和分区信息更优先。
- 加入分区图标：在信息流、帖子卡片、详情页和需要显示分区的位置尽量复用小黑盒分区图标。
- 改造帖子详情：详情页保留原有颜色风格，正文区域左侧展示，右侧放大所在分区入口和相关推荐。
- 优化相关推荐：优先按相同分区、标题/摘要关键词、内容类型和互动热度排序。
- 搜索方案迭代：从本地搜索改为同步原站搜索，避免依赖本地缓存结果。
- 搜索桥优化：点击搜索后后台打开非激活原站搜索页，捕获结果后自动关闭，并将结果回填到 HeyNote 页面，减少黑屏和跳转感。
- 搜索结果解析：第一张图片识别为头像，后续图片识别为帖子图片；继续尝试识别分区名、分区 id 和分区图标。
- 搜索结果 UI 修正：卡片左上角优先显示分区，不再用“文章”占据首位。
- 修复可见乱码：修正 App 中残留的乱码提示和过期 README 搜索说明。
- 项目维护增强：新增 `verify:dist` 脚本，用于检查 Manifest、版本号和构建产物连通性。
- GitHub 标准化：新增 CI workflow、PR 模板、Issue 模板和贡献指南。

## 验证记录

- `npm.cmd run typecheck`
- `npm.cmd run build`
- `npm.cmd run verify:dist`
- 检查扩展 zip 根目录包含 `manifest.json`、`background.js`、`domain-claim.js`、`domain-entry.js` 和 `search-bridge.js`。

## 当前限制

- 搜索仍依赖小黑盒原站页面结构和搜索接口，原站改版可能导致解析规则需要更新。
- 分区识别使用 DOM 和接口字段的保守解析策略，无法保证所有搜索结果都能识别到分区。
- 点赞、收藏、关注、评论等能力继续依赖用户在小黑盒网页端的登录状态和官方接口可用性。

## 后续建议

- 用更多真实搜索关键词截图校准分区 DOM 解析规则。
- 给搜索结果建立专门的解析样例和回归测试数据。
- 将帖子详情的相关推荐、分区入口和搜索桥错误状态继续做成可观察日志，便于定位原站结构变化。
